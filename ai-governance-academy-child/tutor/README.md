# Tutor LMS Integration (CSS-First)

Tutor LMS views (course archive, single course, student dashboard, lesson player,
and quiz interface) are styled primarily via `assets/css/tutor-lms.css` and
`inc/integrations/tutor-lms.php`.

No Tutor LMS PHP template overrides are shipped unless a future markup
requirement cannot be satisfied through CSS or Tutor LMS hooks, ensuring full
compatibility across Tutor LMS plugin updates.
